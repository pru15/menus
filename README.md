# Application de gestion de menus (Python) 

## Idée
A partir d'une liste de recettes ajoutées par l'utilisateur, l'application génère automatiquement une semaine de menus et la liste de courses associée.

## Fonctionnalités actuelles
* Ajout d'une recette avec son nom, ses ingrédients, sa saison et le type de repas (midi ou soir)
* Visualisation des repas prévus sur 5 semaines (les 2 précédentes pour ne pas se répéter, la semaine actuelle, et les deux suivantes pour anticiper encore plus)
* Modification des menus séléctionnés et enregistrement des choix

## Améliorations attendues
* Qualité du code : diviser en plusieurs fichier, meilleure documentation et nommage
* Fonctionnalités : génération aléatoire des menus, génération de la liste de course
* Gestion des erreurs de saisie
* Modification/Suppression d'une recette
